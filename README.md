# FreshMart Rewards – HTML Email Demo

A responsive HTML marketing email for a fictional South African retailer, built to show email-development skills.

## Files

- `index.html` — production template with merge tags
- `preview.html` — preview with sample data
- `images/` — designed graphics, compressed JPGs

## Techniques

- Table-based layout
- Inline CSS
- Outlook MSO ghost tables
- Bulletproof VML buttons
- Mobile media queries
- Dark-mode handling
- Alt text for image blocking
- Merge tags
- Web fonts with fallbacks

https://jorge8017.github.io/html-email-demo/preview.html

FreshMart, FreshCash and Harbour Fuel are fictional brands.
